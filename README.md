# Modul 5 Lernpfad: Gesundheitssorge, Patientenverfügung und Sterben

Interaktive Lernhilfe zum Sachkundelehrgang für berufliche Betreuer (Personensorge 2).

- Lernpfad mit 11 Stationen und Rechtsgrundlagen
- Quiz (67 Fragen) mit Erklärungen
- Karteikarten (64)
- Gesetze im Wortlaut (BGB, FamFG), Quelle: gesetze-im-internet.de
- Übungen: Entscheidungs-Navigator, vier Fälle, Reflexionsfragen

Eine einzelne `index.html`, kein Build-Schritt. Lernfortschritt und Notizen werden nur im Browser gespeichert.

Deployment: Netlify, Publish-Verzeichnis `/`, kein Build-Befehl.
